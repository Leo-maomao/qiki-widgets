# HyperOS 4.0 平台调研清单

目标设备：小米 18 Pro
系统基线：澎湃 OS 4.0.11.0

## 待确认能力

- Android App Widget 标准能力与 HyperOS 桌面实际行为
- 支持的组件尺寸、响应式布局和字体缩放
- 点击、配置页、深链和局部刷新行为
- 周期刷新、系统重启、应用升级后的状态恢复
- 后台网络、通知、自启动和电池优化限制
- 锁屏、负一屏或其他小米专属入口是否开放给第三方
- 公开 SDK、开发文档、权限要求和应用商店审核约束
- BLE 扫描在锁屏、后台和电池优化状态下的持续时间与限制
- AirPods 广播在该机型上的型号、距离和固件兼容性

## 验证方式

所有结论必须至少来自以下一种证据：

1. 小米/HyperOS 官方公开文档
2. Android 官方 API 文档
3. 小米 18 Pro 真机可重复验证的行为

未经验证的系统私有能力不得作为核心产品依赖。

## 调研输出

- 能力矩阵：支持、受限、不支持、待验证
- 最低系统版本和兼容策略
- 权限与后台限制清单
- 真机验收用例
- 侧载和后续应用商店发布风险
